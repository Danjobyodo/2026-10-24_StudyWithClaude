## 1. 目的と問い

論理 $T$ 魔法状態 $|T_L\rangle$（実際には $T^\dagger|+\rangle_L$、両方式で同じ。§2）を 1 個作る次の 2 方式を、**同じ回路レベル雑音モデル**の下で比べる。

* **Kobayashi 方式**：folded surface code（FSC）を D4（twisted $\mathbb Z_2^3$）Clifford 安定化子符号に code switching し、transversal $U=WV$（論理 $T^\dagger$）を作用させて FSC に戻す（[KZH]）。
* **Litinski 方式**：表面符号パッチ上の 15-to-1 魔法状態蒸留（[GoSC] Sec. 3 の配置と、[Lit19] の最適化された蒸留器）。

問い：物理誤り率 $p$ と要求出力誤り $\varepsilon_{\rm target}$ が与えられたとき、どちらが少ない**時空間体積**（物理量子ビット数 × 時間ステップ数）で要求を満たすか。

v4 までは雑音 0 で回路構造と資源を比べた（雑音 0 では蒸留は不要なので「どちらを使うべきか」は決められなかった）。v5 では $p$ を与えて、各方式の出力誤り $\varepsilon(d,p)$ を求め、要求精度を満たす最小の構成どうしを比べる。

## 3. 設定

### 3.1 雑音モデル（両方式に共通）
[Tak] App. A 2 の標準的な回路レベル Pauli 雑音に、アイドル雑音を加えたもの（`NoiseModel`）。

| 位置 | 誤り |
|---|---|
| $k$ 量子ビットゲート（CNOT、CZ、**CCZ**、CS、CS$^\dagger$、$T^\dagger$）の後 | $k$ 量子ビット脱分極（確率 $p$。非恒等 Pauli $4^k-1$ 通りが等確率） |
| 初期化の後 | 反転（$|0\rangle$ に $X$、$|+\rangle$ に $Z$）確率 $p$ |
| 測定の前 | 反転（確率 $p$） |
| 何もしない量子ビット（各時間ステップ） | 1 量子ビット脱分極 $p_{\rm idle}$ |

* **シナリオ A**：$p_{\rm idle}=p$（標準的な SD6 型の回路雑音。主な結果）。
* **シナリオ B**：$p_{\rm idle}=0$（[Tak] と同じ。アイドル時間に対する感度を見るため）。
* CCZ を 1 個の原始ゲート（誤り率 $p$）とするのは**仮定**（ハードウェアでは CCZ は 2 量子ビットゲートより遅く誤りやすい可能性が高い；$p_{\rm ccz}$ を変えられるようにしてある）。
* 「現実的な実機の値」として $p\in\{10^{-4}, 2\times10^{-4}, 3\times10^{-4}, 5\times10^{-4}, 10^{-3}\}$ を評価した（$10^{-3}$ は現在の超伝導・イオンの 2 量子ビットゲートの代表的な値、$10^{-4}$ は近い将来の目標値）。

### 3.2 費用の単位
* 時間：**時間ステップ**（全てのゲート・初期化・測定が 1 ステップ）。表面符号 1 ラウンド（code cycle）＝ 初期化＋CNOT 4 層＋測定 ＝ 6 ステップ（較正回路と同じ。`validation.ipynb` N7）。
* 量子ビット：データ＋補助（測定）量子ビット。
* 体積：Kobayashi は「各ブロックで使う量子ビット数 × そのブロックのステップ数」の和、Litinski は「量子ビット数 × ステップ数（成功確率で割った期待値）」。
* 含めていない費用：古典処理の待ち時間（両方式）、FSC → 通常の回転表面符号パッチへの変換（Kobayashi、未構成。§7 U1）。

### 3.3 パラメータ
* 距離 $d$（Kobayashi は格子 $L=d$；FSC の距離が $d$、D4 相の距離も $L$（$L\le5$ で証明））。
* ラウンド数：S0（FSC 準備）・S1（D4 相）・S4（FSC に戻った後）を $\lceil\kappa d\rceil$。[KZH] は $O(d)$ としか書いていないので、**定数 $\kappa$ は仮定**（既定 1）。$\kappa_{\rm in}$ は感度を測った。
* Litinski：パッチの距離 $d$（GoSC）、$(d_X,d_Z,d_m)$ と 2 段の距離（Lit19）を格子探索して、要求誤りごとに最小体積のものを選ぶ。

## 4. Kobayashi 方式のシミュレーション

### 4.1 回路（`D4SwitchingCircuit`）
v4 で正しさを検証した D4 符号・測定回路・$U$（`d4_lib`、`validation.ipynb` 第 1 部）を、時間ステップ単位の回路に並べた。

| ブロック | 内容 | 出所 |
|---|---|---|
| S0 | FSC のデータを $|+\rangle$ に初期化、FSC の全検査を $\lceil\kappa_0 d\rceil$ ラウンド（$|+_L\rangle$ の準備） | 準備法は [KZH] に記述なし。本研究の構成 |
| S1 | $g$ 量子ビットを $|0\rangle$ に初期化、D4 の全安定化子を $\lceil\kappa_{\rm in}d\rceil$ ラウンド。各ラウンドは **Pauli $Z$ 検査 → 実時間 flux 補正 → X 型 Clifford 安定化子** の順。最後に $Z$ 検査だけのラウンドを 1 回 | [KZH] 手順 2。順序は本研究の選択（flux を CCZ に出会う前に除くため） |
| U | transversal $U=WV$（CNOT、CS、CS$^\dagger$、$T^\dagger$） | [KZH] 式 (8)、手順 3 |
| SO | switch-out：$g$ を $Z$ 基底で読み出し、結果 $a$ から $\kappa=\Gamma(a)$ を求め、$\prod_{v\in\kappa}S^g_v$ の CZ 部分を適用 | [KZH] 手順 4 |
| S4 | FSC の全検査を $\lceil\kappa_{\rm out}d\rceil$ ラウンド | [KZH] 手順 4 |
| FIN | 雑音なしの FSC 1 ラウンド（論理誤りの評価用の「仮想的な誤り訂正」） | [Tak] Sec. VI D |

* **X 型 Clifford 安定化子の測定**：補助 $|+\rangle$ → 補助を制御とする CNOT（X 部分）と CCZ（補助, $i$, $j$）（CZ 部分）→ $X$ 測定。**この回路は [KZH] に無く本研究の構成**（v4 V9 で理想射影測定であることを確認）。$Z$ 検査は通常の CNOT 回路。
* **スケジュール**：測定回路を可換クラスに分け、クラス内を層に詰める（v4 の上界スケジュール、V10 で妥当性を確認）。1 ラウンドのステップ数は D4 の $Z$ 検査 6、D4 の X 型安定化子 28、FSC 14、$U$ 5（$d$ によらない）。**最適化していない**：FSC のラウンドは表面符号の 6 ステップに比べて長く、Kobayashi 方式に不利な側の近似。
* 量子ビット数 $12d^2+4d-1$、時間ステップ数 $62d+16$（$\kappa=1$；`noisy_cost_comparison.ipynb` II-3 で回路から直接数え、多項式で厳密に一致）。

### 4.2 非 Clifford 回路のシミュレーション：Takada らの方法（Pauli proxy）を**採用**
D4 相の測定回路は CCZ を、$U$ は CS と $T^\dagger$ を含むので、stim の安定化子シミュレーションは直接使えない。状態ベクトルは $d=3$ でも 119 量子ビットで不可能。[Tak] の **Clifford-stabilizer simulation（Pauli proxy 法、Algorithm 2）**を本研究で実装して使った（彼らのコードは使っていない）。

**仕組み**（`FastShot`）：1 ショットごとに、
1. 雑音モデルから Pauli 誤りを標本する。
2. 真の回路から対角第 3 階層ゲート $D$（CCZ、CS、CS$^\dagger$、$T^\dagger$）を取り除き、Clifford 部分だけを stim の `TableauSimulator` で実行する。
3. 標本した誤りと、実際に適用した $X$ 補正の **X 成分 $e$** を、Clifford ゲート（CNOT）を通して前向きに追跡する（$Z$ 成分は対角ゲートと可換なので追跡不要）。
4. $D$ の位置で X 成分 $e$ が $D$ の台に乗っていれば、$D$ の代わりに **ドレッシング $C_e=D^\dagger X^e D X^e$**（S、Z、CZ の積＝Clifford）を挿入する。$D X^e = X^e D C_e$ なので、「誤り $X^e$ が $D$ を通過した」効果を Clifford で正確に表す（[Tak] Fig. 14、式 (165) の制御 Pauli ドレッシング）。
5. 理想状態に対しては $D$ が「Clifford 安定化子の固有値」として作用するだけで、測定統計は変わらない。この「理想部分は Pauli の固有値として扱い、誤りとの交換で生じる Clifford だけを残す」ことが厳密であるための十分条件が [Tak] の Definition 2 と Sec. VIII。

**適用条件の確認**（**仮定せず検証した**；`takada_conditions`、`validation.ipynb` N1、$L=2..6$ 全 PASS）：
* (a) X 型 Clifford 安定化子の X 因子と CZ 因子の台が互いに素（transversal。式 (131)）。
* (b) CZ・S に対する X/Y 誤りのドレッシングは単一量子ビット $Z$ で、全量子ビットでドレッシングの軸が $Z$。
* (c) 測定する生成元どうしの群交換子が、その時点の $Z$ 安定化子の張る空間に入る（実効的可換性、式 (58) / Lemma 1）。switch-in では FSC $|+_L\rangle\otimes|0\rangle_g$ の生成元を D4 側の CZ でドレスしたもの（$|0\rangle_g$ 上では自明）と、CZ でドレスした論理 $\bar X$（$\mathbb F_2$ の連立方程式で存在を示す）を使う（Sec. VIII B の生成元の選び方）。裸の FSC 生成元ではこの条件は成り立たない。
* (d) primary-support exactness（Definition 1）：X 台が線形独立。
* (e) $U$ と switch-out の補正網は CNOT と対角第 3 階層ゲートのみ（Sec. VIII A、式 (178)）。
* (f) 出力の論理安定化子 $\bar H$ が Clifford で、FSC の X 検査と実効的に可換。

**数値による直接の検証**（`validation.ipynb` N3）：$L=1,2$ で、同じ誤り・同じ測定結果・同じランダムな $X$ 補正を Pauli proxy 回路と**真の非 Clifford 回路の厳密な疎状態ベクトル**（CCZ・CS・$T^\dagger$ をそのまま作用、`TrueSim`）に与え、全測定（数百回）で「proxy で決定的 ⇔ 真の回路で確率 1、proxy でランダム ⇔ 真の回路で確率 1/2」と、最後の $\langle\bar H\rangle$ が一致することを確認した（並列・逐次の両スケジュール）。

**本研究で加えた工夫**（いずれも [Tak] の枠組みの中）：
* S0 は Clifford 回路なので、S1 の開始時に stim の状態から $Z$ 検査の符号を読み、X フレームを $\mathbb F_2$ の連立方程式で求める（解の不定性は理想状態の X 安定化子・論理 $X$ で、Algorithm 2 の結果に影響しない）。[Tak] Algorithm 3 は不要。
* switch-out の補正 $\kappa=\Gamma(a)$ は測定結果に依存する CZ なので、「遅延測定」形式で表す：測定前の $g$ 量子ビットを制御とする**雑音なしの仮想 CCZ 網**で $\Gamma(a_{\rm 読み出し})$ に応じた CZ を作用させ（この CCZ も Pauli proxy 法で扱う）、その後で $Z^g$ を読み出す。実際のプロトコルが適用する CZ（復号後の $a$ から求めた $\Gamma(a_{\rm 復号後})$）との差（Clifford）と、物理的な CZ ゲートの雑音を加える。
* 出力の評価（[Tak] Sec. VI D）：雑音なしの FSC ラウンドで復号した後、理想出力 $D_F|+_L\rangle$（$F(a)$ は v4 で検証した位相公式）の論理 Clifford 安定化子 $\bar H=X^tD_\Delta$ の Pauli proxy の期待値 $\langle\bar H\rangle\in\{1,0,-1\}$ を stim で読み、不忠実度 $(1-\langle\bar H\rangle)/2\in\{0,1/2,1\}$ を 1 ショットの値とする。出力誤り $\varepsilon_K$ はその平均（$\bar H$ の誤り＝論理 $Z$ 誤りに加え、$T$ 状態の非 Pauli 誤りも正しく数える）。

### 4.3 復号器（**本研究の構成**。[Dav] の JIT decoder は参照できなかった）
* **flux（$Z$ 検査で見える $X$ 誤り）**：毎ラウンド、それまでの全ラウンドの時空間グラフ（未来側は開いた境界）を最小重み完全マッチング（PyMatching）で復号し、確定した空間的な辺の $X$ 補正を**その場で物理的に適用**（即時フィードフォワード）。S0 の終わりと $U$ の前では全て確定する。[KZH] 手順 2 の「flux を実時間でペアにする」の素朴な実装。辺の重みは回路の雑音位置から見積もった現象論的な確率。
* **switch-out の $g$ 読み出し**：$g$ の $Z$ 読み出しから作った検出器（D4 の $Z$ 検査の積との関係を $\mathbb F_2$ で求めたもの）を flux のグラフに加え、$g$ の読み出し誤りと S1 の $g$ flux をまとめて復号して、補正後の配置 $a$ から $\kappa=\Gamma(a)$ を決める。
* **charge（X 型検査で見える $Z$ 誤り）**：プロトコル終了後、Pauli proxy 回路の誤りモデル（stim の detector error model）上の MWPM で、論理 $\bar H$ の反転を予測する。D4 相の X 型安定化子の結果は、flux があったラウンドで CZ のドレッシングによりランダムになるので、flux の位置から該当する辺の重みを下げる（消失誤りとして扱う）。switch-out をまたぐ検出器では、FSC の $r$・$b$ 検査に対し 3 種の電荷（$r,b,g=r+b$）があり、どの基底を選んでも一部の誤りが 4 個の検出器にまたがる（ハイパーエッジ）。2 つの基底（$\{D_r,D_b\}$ と $\{D_r,D_r+D_b\}$）で復号し、重みの小さい方を採る（同じ誤りの標本で比べて、1 つの基底だけの場合より $\varepsilon_K$ が約 1.5〜1.8 倍小さくなった）。
* **限界**：最適ではない（1 個の故障で失敗する場合がある。$d=3$ で全 58,377 通りのうち 228 通り（0.39%）、$d=5$ で無作為抽出 6,000 通りのうち 1 通り（0.017%）：`validation.ipynb` N5）。主な原因は (i) CCZ ガジェット内の故障による非 Pauli な効果（CZ のドレッシング）を charge 復号器の誤りモデルが含まないこと、(ii) 上のハイパーエッジ。したがって **$\varepsilon_K$ は最適な復号器で達成できる値より大きい（保守的、Kobayashi 方式に不利な側）**。

### 4.4 モンテカルロと当てはめ
* `D4_noisy_simulation.ipynb`：$d\in\{3,5,7,9\}$、$p$ 5 点、シナリオ A/B、1 点あたり最大 20 分または失敗 200 回。$\kappa_{\rm in}\in\{0.4,0.6,1.5\}$ の感度（シナリオ B、$p=2\times10^{-4}$、$d=5,7$）。
* **診断用の追加の実行**（`quiet_window=True`）：切り替えの時間窓（D4 相最後のラウンド、$U$ 直前の $Z$ ラウンド、$U$、switch-out、FSC に戻った最初のラウンド）だけ雑音を 0 にする（復号器の事前確率は元の雑音のまま）。復号器が 1 個の故障を訂正できない場所はこの窓に集中しているので、「窓の誤りを完全に扱えた場合」の楽観的な限界を与える。物理的なモデルではない。$d=3..9$、$p\in\{3,5,10\}\times10^{-4}$、A/B。

## 5. Litinski 方式のモデル

### 5.1 誤り予算モデル（[Lit19] の方法、文献どおり）
蒸留回路を 5 個の論理量子ビット上の $Z$ 型 π/8 回転の列とし、各回転の後に確率 $p_1,p_2,p_3$ で $P_{\pi/2}$（Pauli）、$P_{-\pi/4}$、$P_{\pi/4}$ の誤りが起きるとする。入力魔法状態の誤り（$p/3$ ずつ）と、格子手術の測定誤り・補助領域の誤り（$p_L$ × 距離 × 面積に比例）が $p_1,p_2$ に加わる。パッチは 1 cycle あたり $X$・$Z$ それぞれ $0.5\,p_L(d)$ の記憶誤り。5 量子ビットの密度行列を厳密に計算し（128 ビット演算で検証）、事後選択後の出力の不忠実度と成功確率を得る。量子ビット数と cycle 数は [Lit19] の費用式。公開ノートの 8 件を再現（N6）。

### 5.2 GoSC の配置への当てはめ（**本研究の当てはめ。仮定を含む**）
* **GoSC 15-to-1**（Fig. 17c：11 tiles × 11τ、1τ = $d$ cycles）：単一の距離 $d$。11 回転（Fig. 15、M1 で照合済み）それぞれに、時間方向の測定誤り $0.5\,p_L d$ と、2 tile の補助領域の空間方向の誤り $0.5\cdot2\,p_Ld$ を加え、各 tile に $0.5\,p_Ld$ の記憶誤り。量子ビット $11\times2d^2$、時間 $11d$ cycles / 成功確率。

### 5.3 パッチの論理誤り率 $p_L(d,p)$ の較正（両方式を同じ雑音で比べるため）

## 8. 結果の要約

ノートブックの数値（`results/cost_comparison.csv`、`figures/*.png`）の要約。

**表面符号の較正**（§5.3）：$p_L=A(p/p_{\rm th})^{(d+1)/2}$ で、A：$A=0.083$, $p_{\rm th}=0.0086$；B：$A=0.037$, $p_{\rm th}=0.0116$（GoSC 式 (10) は $A=0.1$, $p_{\rm th}=0.01$）。

**Kobayashi 方式の $\varepsilon_K$**（本来のシミュレーション、`window = noisy`）

| $p$ | B: $d=3$ | $d=5$ | $d=7$ | $d=9$ | A: $d=3$ | $d=5$ | $d=7$ | $d=9$ |
|---|---|---|---|---|---|---|---|---|
| $10^{-4}$ | 6.5e-4 | 3.1e-4 | 7.2e-4 | 3.5e-4 | 2.9e-3 | 5.4e-4 | 6.4e-4 | 3.5e-4 |
| $3\times10^{-4}$ | 2.5e-3 | 1.2e-3 | 1.5e-3 | 9.8e-4 | 1.8e-2 | 5.5e-3 | 3.5e-3 | 3.8e-3 |
| $10^{-3}$ | 1.1e-2 | 7.1e-3 | 7.6e-3 | 1.3e-2 | 0.18 | 0.18 | 0.18 | 0.21 |

（$d=9$ の小さい $p$ は失敗数が少なく（2〜7 回）不確か。）
* $d\ge5$ で $d$ による改善が無く、$\varepsilon_K\approx(3\text{–}8)p$（B）。窓の床 $W(p)$ の当てはめは $p=10^{-4}$ で $W\approx3.2p$（A）・$3.4p$（B）。
* switch-in のラウンド数の感度（B、$p=2\times10^{-4}$）：$\kappa_{\rm in}=0.4/0.6/1.0/1.5$ で $d=5$：2.3e-3 / 8.4e-4 / 5.9e-4 / 7.1e-4、$d=7$：1.0e-3 / 8.4e-4 / 1.0e-3 / 7.1e-4。窓の床が支配するため $\kappa_{\rm in}\ge0.6$ でほぼ一定。
* 診断（`window = quiet`、切り替えの窓だけ雑音 0）：B の $p=10^{-3}$ で $d=3,5,7,9$ が 1.7e-3, 1.2e-3, 4.5e-4, 5.9e-4、$p\le5\times10^{-4}$ の $d=9$ は失敗 0。当てはめた bulk の抑制率は距離 2 ごとに A：15 倍・B：24 倍（$p=10^{-4}$）。A の $p=10^{-3}$ は閾値付近（抑制なし）。

**費用**：Kobayashi 方式は量子ビット $12d^2+4d-1$、時間 $62d+16$ ステップ、体積 $632d^3+388d^2-14d-8$（$\kappa=1$；回路から直接数えた値と $d=3..11$ で一致）。

**比較**（要求誤りごとの最小体積の比 Kobayashi / Litinski）：本来のシミュレーションでは Kobayashi はどの条件でも要求 $10^{-4}$ に届かない。楽観的な限界（窓の誤りを完全に扱えた場合）でも、要求 $10^{-6}$ 以下では A で 5.1〜59 倍（$p\le5\times10^{-4}$、$p=10^{-3}$ では届かない）、B で 1.0〜58 倍。Kobayashi が並ぶか下回るのは B・要求 $10^{-4}$・$p\le2\times10^{-4}$（0.36〜0.52 倍）と B・$p=10^{-4}$・要求 $10^{-6}$（1.0 倍）だけ。

**解釈**：(i) 本研究の実装では、Kobayashi 方式の性能は切り替えの窓の復号で決まっており、これを扱う JIT 復号器（[Dav]）が実用性の鍵である。(ii) 窓を理想化しても、D4 相のラウンドが長く（雑音の位置が多く）実効的な閾値が低いため、実用的な要求精度では 15-to-1 蒸留の方が体積が小さい。この結論は窓の扱いに対して頑健だが、楽観的な限界の $d>9$ への外挿は少数の点に基づき不確か。(iii) 結論を変えうる要因：測定スケジュールの最適化（FSC 14 → 6 ステップ、D4 ラウンドの短縮）、CCZ の実際の誤り率（$p$ より大きければ Kobayashi にさらに不利）、FSC → パッチ変換（未計上で Kobayashi に有利な側の省略）。
