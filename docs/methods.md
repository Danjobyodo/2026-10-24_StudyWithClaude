# 方法・設定・仮定（v5：物理誤り率を与えたときの資源比較）

この文書は、研究の目的・設定・シミュレーション手法・仮定と未解決問題・検証の範囲をまとめたもの（v4 までの `docs/01`〜`04` を統合し、v5 の雑音付きシミュレーションの説明を加えた）。ノートブックの実行方法と結果の要約は `README.md`。

状態の区分：**検証済み**（文献の記述、または本研究の検証で確定）／**仮定に依存**（パラメータとして明示、結果はその値に依存）／**未解決**（比較から除外、または例示のみ）。

## 1. 目的と問い

論理 $T$ 魔法状態 $|T_L\rangle$（実際には $T^\dagger|+\rangle_L$、両方式で同じ。§2）を 1 個作る次の 2 方式を、**同じ回路レベル雑音モデル**の下で比べる。

* **Kobayashi 方式**：folded surface code（FSC）を D4（twisted $\mathbb Z_2^3$）Clifford 安定化子符号に code switching し、transversal $U=WV$（論理 $T^\dagger$）を作用させて FSC に戻す（[KZH]）。
* **Litinski 方式**：表面符号パッチ上の 15-to-1 魔法状態蒸留（[GoSC] Sec. 3 の配置と、[Lit19] の最適化された蒸留器）。

問い：物理誤り率 $p$ と要求出力誤り $\varepsilon_{\rm target}$ が与えられたとき、どちらが少ない**時空間体積**（物理量子ビット数 × 時間ステップ数）で要求を満たすか。

v4 までは雑音 0 で回路構造と資源を比べた（雑音 0 では蒸留は不要なので「どちらを使うべきか」は決められなかった）。v5 では $p$ を与えて、各方式の出力誤り $\varepsilon(d,p)$ を求め、要求精度を満たす最小の構成どうしを比べる。

## 3. 設定

### 3.1 雑音モデル（両方式に共通）
[Tak] App. A 2 の標準的な回路レベル Pauli 雑音に、アイドル雑音を加えたもの（`NoiseModel`）。

| 位置 | 誤り |
|---|---|
| $k$ 量子ビットゲート（CNOT、CZ、**CCZ**、CS、CS$^\dagger$、$T^\dagger$）の後 | $k$ 量子ビット脱分極（確率 $p$。非恒等 Pauli $4^k-1$ 通りが等確率） |
| 初期化の後 | 反転（$|0\rangle$ に $X$、$|+\rangle$ に $Z$）確率 $p$ |
| 測定の前 | 反転（確率 $p$） |
| 何もしない量子ビット（各時間ステップ） | 1 量子ビット脱分極 $p_{\rm idle}$ |

* **シナリオ A**：$p_{\rm idle}=p$（標準的な SD6 型の回路雑音。主な結果）。
* **シナリオ B**：$p_{\rm idle}=0$（[Tak] と同じ。アイドル時間に対する感度を見るため）。
* CCZ を 1 個の原始ゲート（誤り率 $p$）とするのは**仮定**（ハードウェアでは CCZ は 2 量子ビットゲートより遅く誤りやすい可能性が高い；$p_{\rm ccz}$ を変えられるようにしてある）。
* 「現実的な実機の値」として $p\in\{10^{-4}, 2\times10^{-4}, 3\times10^{-4}, 5\times10^{-4}, 10^{-3}\}$ を評価した（$10^{-3}$ は現在の超伝導・イオンの 2 量子ビットゲートの代表的な値、$10^{-4}$ は近い将来の目標値）。

### 3.2 費用の単位
* 時間：**時間ステップ**（全てのゲート・初期化・測定が 1 ステップ）。表面符号 1 ラウンド（code cycle）＝ 初期化＋CNOT 4 層＋測定 ＝ 6 ステップ（較正回路と同じ。`validation.ipynb` N7）。
* 量子ビット：データ＋補助（測定）量子ビット。
* 体積：Kobayashi は「各ブロックで使う量子ビット数 × そのブロックのステップ数」の和、Litinski は「量子ビット数 × ステップ数（成功確率で割った期待値）」。
* 含めていない費用：古典処理の待ち時間（両方式）、FSC → 通常の回転表面符号パッチへの変換（Kobayashi、未構成。§7 U1）。

### 3.3 パラメータ
* 距離 $d$（Kobayashi は格子 $L=d$；FSC の距離が $d$、D4 相の距離も $L$（$L\le5$ で証明））。
* ラウンド数：S0（FSC 準備）・S1（D4 相）・S4（FSC に戻った後）を $\lceil\kappa d\rceil$。[KZH] は $O(d)$ としか書いていないので、**定数 $\kappa$ は仮定**（既定 1）。$\kappa_{\rm in}$ は感度を測った。
* Litinski：パッチの距離 $d$（GoSC）、$(d_X,d_Z,d_m)$ と 2 段の距離（Lit19）を格子探索して、要求誤りごとに最小体積のものを選ぶ。

## 4. Kobayashi 方式のシミュレーション

### 4.1 回路（`D4SwitchingCircuit`）
v4 で正しさを検証した D4 符号・測定回路・$U$（`d4_lib`、`validation.ipynb` 第 1 部）を、時間ステップ単位の回路に並べた。

| ブロック | 内容 | 出所 |
|---|---|---|
| S0 | FSC のデータを $|+\rangle$ に初期化、FSC の全検査を $\lceil\kappa_0 d\rceil$ ラウンド（$|+_L\rangle$ の準備） | 準備法は [KZH] に記述なし。本研究の構成 |
| S1 | $g$ 量子ビットを $|0\rangle$ に初期化、D4 の全安定化子を $\lceil\kappa_{\rm in}d\rceil$ ラウンド。各ラウンドは **Pauli $Z$ 検査 → 実時間 flux 補正 → X 型 Clifford 安定化子** の順。最後に $Z$ 検査だけのラウンドを **2 回**（$U$ の直前の flux を確実に除くため。1 回では、最後の $Z$ ラウンドの故障が $U$ を通って訂正できなくなる単一故障の主因だった：§4.3） | [KZH] 手順 2（$O(d)$ ラウンドの D4 安定化子の測定の一部）。順序と $Z$ ラウンドの数は本研究の選択 |
| U | transversal $U=WV$（CNOT、CS、CS$^\dagger$、$T^\dagger$） | [KZH] 式 (8)、手順 3 |
| SO | switch-out：$g$ を $Z$ 基底で読み出し（1 ステップ）、復号した結果 $a$ から $\kappa=\Gamma(a)$ を求め、$\prod_{v\in\kappa}S^g_v$ の CZ 部分（同じ対が偶数回なら相殺）を**固定の層スケジュール**で適用（全 $S^g_v$ の CZ 対の和集合の辺彩色；層数は測定結果によらない最悪値で時間に数える。全ての $d$ で 1 層） | [KZH] 手順 4。スケジュールは本研究の構成 |
| S4 | FSC の全検査を $\lceil\kappa_{\rm out}d\rceil$ ラウンド | [KZH] 手順 4 |
| FIN | 雑音なしの FSC 1 ラウンド（論理誤りの評価用の「仮想的な誤り訂正」） | [Tak] Sec. VI D |

* **X 型 Clifford 安定化子の測定**：補助 $|+\rangle$ → 補助を制御とする CNOT（X 部分）と CCZ（補助, $i$, $j$）（CZ 部分）→ $X$ 測定。**この回路は [KZH] に無く本研究の構成**（v4 V9 で理想射影測定であることを確認）。$Z$ 検査は通常の CNOT 回路。
* **スケジュール**：測定回路を可換クラスに分け、クラス内を層に詰める（v4 の上界スケジュール、V10 で妥当性を確認）。1 ラウンドのステップ数は D4 の $Z$ 検査 6、D4 の X 型安定化子 28、FSC 14、$U$ 5（$d$ によらない）。
  * FSC の全検査を同時に測る**並列スケジュール**（6 CNOT 層、ラウンド 8 ステップ；$\mathcal L_{rb}$ の重さ 6 の $X^rX^b$ 検査があるので表面符号の 4 層にはできない）を探索し、stim のメモリ実験で決定性と回路レベルの距離 $\ge L$ を確認した（`validation.ipynb` N10）。しかし**本研究の flux 復号器では、並列スケジュールの方が出力誤りが大きくなった**（同じ条件の比較で、B・$d=5$・$p=5\times10^{-4}$：$0.95\times10^{-3}\to1.4\times10^{-3}$、A・$d=7$・$p=3\times10^{-4}$：$1.2\times10^{-3}\to2.8\times10^{-3}$）。X 検査と Z 検査を交互に置くと、X 検査の補助量子ビットのフック誤りが Z 検査の検出に複数のラウンドにまたがって現れ、flux 復号器の現象論的な誤りモデルがそれを表さないため。そこで本番は 14 ステップのスケジュールでシミュレーションし、8 ステップで数えた場合の費用を**時間だけの感度**として比較表に示す（`*_fsc8`）。D4 相の X 型安定化子（28 ステップ）は、演算子として可換でない Clifford 安定化子を含むので、可換クラスの順に測る必要がある。
* 量子ビット数 $12d^2+4d-1$、時間ステップ数 $62d+21$（$\kappa=1$、$U$ の前の $Z$ ラウンド 2 回、switch-out＝読み出し 1＋CZ 1 層；`noisy_cost_comparison.ipynb` II-3 で回路から直接数え、多項式で厳密に一致）。FSC を 8 ステップで数えると $50d+21$。
* **フィードフォワードの $X$ 補正**（flux 復号器の補正、switch-out 後の補正）は、雑音なし・時間 0 の Pauli 層として適用する（理想化。雑音モデルの例外）。後続の非 Clifford ゲートがあるので Pauli フレームとして後回しにはせず、Pauli proxy の X フレームにも反映する（N3b で真の回路と一致を確認）。

### 4.2 非 Clifford 回路のシミュレーション：Takada らの方法（Pauli proxy）を**採用**
D4 相の測定回路は CCZ を、$U$ は CS と $T^\dagger$ を含むので、stim の安定化子シミュレーションは直接使えない。状態ベクトルは $d=3$ でも 119 量子ビットで不可能。[Tak] の **Clifford-stabilizer simulation（Pauli proxy 法、Algorithm 2）**を本研究で実装して使った（彼らのコードは使っていない）。

**仕組み**（`FastShot`）：1 ショットごとに、
1. 雑音モデルから Pauli 誤りを標本する。
2. 真の回路から対角第 3 階層ゲート $D$（CCZ、CS、CS$^\dagger$、$T^\dagger$）を取り除き、Clifford 部分だけを stim の `TableauSimulator` で実行する。
3. 標本した誤りと、実際に適用した $X$ 補正の **X 成分 $e$** を、Clifford ゲート（CNOT）を通して前向きに追跡する（$Z$ 成分は対角ゲートと可換なので追跡不要）。
4. $D$ の位置で X 成分 $e$ が $D$ の台に乗っていれば、$D$ の代わりに **ドレッシング $C_e=D^\dagger X^e D X^e$**（S、Z、CZ の積＝Clifford）を挿入する。$D X^e = X^e D C_e$ なので、「誤り $X^e$ が $D$ を通過した」効果を Clifford で正確に表す（[Tak] Fig. 14、式 (165) の制御 Pauli ドレッシング）。
5. 理想状態に対しては $D$ が「Clifford 安定化子の固有値」として作用するだけで、測定統計は変わらない。この「理想部分は Pauli の固有値として扱い、誤りとの交換で生じる Clifford だけを残す」ことが厳密であるための十分条件が [Tak] の Definition 2 と Sec. VIII。

**適用条件の確認**（仮定せず確認した；`takada_conditions`、`validation.ipynb` N1、$L=2..7$ と 9 で全 PASS。**有限サイズの代数的確認であり、一般の $L$ の証明ではない**。演算子の比較は大域位相だけを許す厳密比較（第 3 回レビューで、以前の要素の絶対値の比較が $I$ と $Z$ を区別できない欠陥を指摘され修正。修正後も全 PASS で、ドレッシング自体の誤りではなかった））：
* (a) X 型 Clifford 安定化子の X 因子と CZ 因子の台が互いに素（transversal。式 (131)）。
* (b) CZ・S に対する X/Y 誤りのドレッシングは単一量子ビット $Z$ で、全量子ビットでドレッシングの軸が $Z$。
* (c) 測定する生成元どうしの群交換子が、その時点の $Z$ 安定化子の張る空間に入る（実効的可換性、式 (58) / Lemma 1）。switch-in では FSC $|+_L\rangle\otimes|0\rangle_g$ の生成元を D4 側の CZ でドレスしたもの（$|0\rangle_g$ 上では自明）と、CZ でドレスした論理 $\bar X$（$\mathbb F_2$ の連立方程式で存在を示す）を使う（Sec. VIII B の生成元の選び方）。裸の FSC 生成元ではこの条件は成り立たない。
* (d) primary-support exactness（Definition 1）：X 台が線形独立。
* (e) $U$ と switch-out の補正網は CNOT と対角第 3 階層ゲートのみ（Sec. VIII A、式 (178)）。
* (f) 出力の論理安定化子 $\bar H$ が Clifford で、FSC の X 検査と実効的に可換。

**数値による直接の検証**（`validation.ipynb` N3）：同じ誤り・同じ測定結果を Pauli proxy 回路と**真の非 Clifford 回路の厳密な疎状態ベクトル**（CCZ・CS・$T^\dagger$ をそのまま作用、`TrueSim`）に与え、全測定で「proxy で決定的 ⇔ 真の回路で確率 1、proxy でランダム ⇔ 真の回路で確率 1/2」と、最後の $\langle\bar H\rangle$ が一致することを確認した。(a) $L=1,2$、ランダムな $X$ 補正（並列・逐次の両スケジュール）。(b) N3b：$L=2$ で**本番と同じ適応処理の全経路**（`D4Experiment.shot` そのもの：flux 復号器の補正、switch-out の復号済み読み出し、物理的な補正 CZ の層とその雑音、Pauli frame、charge 復号器）。N3b は S0 をその理想出力（＋ランダムな Pauli 誤り）で置き換える（S0 は Clifford 回路で stim だけで厳密だが、多数の補助量子ビットを含む状態ベクトルはメモリに入らない）。$L\ge3$ は状態ベクトルでは確認できない。

**本研究で加えた工夫**（いずれも [Tak] の枠組みの中）：
* S0 は Clifford 回路なので、S1 の開始時に stim の状態から $Z$ 検査の符号を読み、X フレームを $\mathbb F_2$ の連立方程式で求める（解の不定性は理想状態の X 安定化子・論理 $X$ で、Algorithm 2 の結果に影響しない）。[Tak] Algorithm 3 は不要。
* switch-out：シミュレーションでは測定結果に依存する CZ を「遅延測定」形式で表す（測定前の $g$ を制御とする**雑音なしの仮想 CCZ 網**、Pauli proxy 法で扱う）。これは**シミュレーション上の表現であり物理操作ではない**ので、その仮想モーメントは時間にもアイドル雑音にも数えない。読み出しの後、(1) 仮想網の CZ（$\Gamma(a_{\rm 読み出し})$）を雑音なしで取り除き（Clifford の帳簿付け）、(2) flux 復号器の $X$ 補正を適用し、(3) 物理的な補正 $\mathrm{CZ}(\Gamma(a_{\rm 復号後}))$ を固定の層スケジュールで、各 CZ の後に 2 量子ビット脱分極、その層で使わないデータ量子ビットにアイドル雑音を入れて順に適用する（途中の Pauli 誤りが後の CZ で伝播する効果が正確に入る）。全体で、実際のプロトコル（読み出し → 古典処理 → 補正の層）の時間・雑音と一致する（第 3 回レビューの指摘を受けて、以前の「差の CZ を適用し、雑音を後から加える」方法から変更）。
* 出力の評価（[Tak] Sec. VI D）：雑音なしの FSC ラウンドで復号した後、理想出力 $D_F|+_L\rangle$（$F(a)$ は v4 で検証した位相公式）の論理 Clifford 安定化子 $\bar H=X^tD_\Delta$ の Pauli proxy の期待値 $\langle\bar H\rangle\in\{1,0,-1\}$ を stim で読み、不忠実度 $(1-\langle\bar H\rangle)/2\in\{0,1/2,1\}$ を 1 ショットの値とする。出力誤り $\varepsilon_K$ はその平均（$\bar H$ の誤り＝論理 $Z$ 誤りに加え、$T$ 状態の非 Pauli 誤りも正しく数える）。

### 4.3 復号器（**本研究の構成**。[Dav] の JIT decoder は参照できなかった）
* **flux（$Z$ 検査で見える $X$ 誤り）**：毎ラウンド、それまでの全ラウンドの時空間グラフ（未来側は開いた境界）を最小重み完全マッチング（PyMatching）で復号し、確定した空間的な辺の $X$ 補正を**その場で物理的に適用**（即時フィードフォワード）。S0 の終わりと $U$ の前では全て確定する。[KZH] 手順 2 の「flux を実時間でペアにする」の素朴な実装。辺の重みは回路の雑音位置から見積もった現象論的な確率。
* **switch-out の $g$ 読み出し**：$g$ の $Z$ 読み出しから作った検出器（D4 の $Z$ 検査の積との関係を $\mathbb F_2$ で求めたもの）を flux のグラフに加え、$g$ の読み出し誤りと S1 の $g$ flux をまとめて復号して、補正後の配置 $a$ から $\kappa=\Gamma(a)$ を決める。
* **charge（X 型検査で見える $Z$ 誤り）**：プロトコル終了後、Pauli proxy 回路の誤りモデル（stim の detector error model）上の MWPM で、論理 $\bar H$ の反転を予測する。D4 相の X 型安定化子の結果は、flux があったラウンドで CZ のドレッシングによりランダムになるので、flux の位置から該当する辺の重みを下げる（消失誤りとして扱う）。switch-out をまたぐ検出器では、FSC の $r$・$b$ 検査に対し 3 種の電荷（$r,b,g=r+b$）があり、どの基底を選んでも一部の誤りが 4 個の検出器にまたがる（ハイパーエッジ）。2 つの基底（$\{D_r,D_b\}$ と $\{D_r,D_r+D_b\}$）で復号し、重みの小さい方を採る（同じ誤りの標本で比べて、1 つの基底だけの場合より $\varepsilon_K$ が約 1.5〜1.8 倍小さくなった）。
* **限界：この回路と復号器は 1 個の故障を必ずしも訂正しない**（`validation.ipynb` N5）。N5 は全ての雑音位置（switch-out の動的な CZ を含む）× 全 Pauli を 2 つの測定分岐で試し、確率で重み付けした一次の係数 $c_1$（$\varepsilon_K\approx c_1p$）を求める。$U$ の直前の $Z$ ラウンドを 2 回にした現在の回路では：$d=3$（全列挙）は A で 60,891 通りのうち 275 通りが失敗、$c_1=15.7$（窓の中 15.4、外 0.3）、B で 180 通り、$c_1=4.2$（窓の中 4.0、外 0.2）；窓の中を全列挙すると $d=5$ で $c_1=0.88$（A）・$0.27$（B）、**$d=7$（B）で失敗 0（$c_1=0$）**。$Z$ ラウンドが 1 回だった v5.1 では $c_1=3.0$（A, $d=5$）、3.1（B, $d=5$）、3.9（B, $d=7$）で、失敗の大部分が $U$ 直前の $Z$ ラウンドの故障（その後で起きて $U$ を通る $X$ 誤り）だった。残る失敗は D4 相最後の X 型ラウンドの CCZ ガジェット内の故障（CZ のドレッシングによる非 Pauli な効果を charge 復号器の誤りモデルが含まない）が主で、switch-out の時間境界のハイパーエッジも寄与しうる。さらに $d=7,9$ では、窓の中の 2 個以上の故障による誤り（$\propto p^{2.4}$ 程度）が残る（§8）。復号器・測定ガジェット・順序・境界のどれに帰すべきかの完全な分類はしていない（未解決）。符号距離 $d$ と回路の故障距離は同じではない。

### 4.4 モンテカルロと当てはめ
* `D4_noisy_simulation.ipynb`：$d\in\{3,5,7,9\}$、$p$ 5 点、シナリオ A/B、1 点あたり最大 20 分または失敗 200 回。$\kappa_{\rm in}\in\{0.4,0.6,1.5\}$ の感度（シナリオ B、$p=2\times10^{-4}$、$d=5,7$）。
* 保存：各 worker が chunk ごとに CSV に追記し、各行に `run_id`・条件 ID・chunk 番号・乱数の種を記録する（中断後に重複なく再開できる）。
* **診断用の別の実験**（`quiet_window=True`、`window = quiet`）：切り替えの時間窓（D4 相最後のラウンド、$U$ 直前の $Z$ ラウンド、$U$、switch-out、FSC に戻った最初のラウンド）だけ雑音を 0 にし、**同じ復号器**で評価する（復号器の事前確率は元の雑音のまま）。1 個の故障の失敗の大部分（$c_1$ のほぼ全て）がこの窓にあるので、「窓の外の誤りがどれだけ抑えられるか」を見る。**物理的なモデルではなく、最適な復号器の性能の上界・下界でもない**（最適な復号器は窓の外の誤りも改善しうるし、窓の誤りの影響が 0 になるとも限らない；窓の外にも少数の単一故障の失敗がある）。$d=3..9$、$p\in\{3,5,10\}\times10^{-4}$、A/B。

## 5. Litinski 方式のモデル

### 5.1 誤り予算モデル（[Lit19] の方法、文献どおり）
蒸留回路を 5 個の論理量子ビット上の $Z$ 型 π/8 回転の列とし、各回転の後に確率 $p_1,p_2,p_3$ で $P_{\pi/2}$（Pauli）、$P_{-\pi/4}$、$P_{\pi/4}$ の誤りが起きるとする。入力魔法状態の誤り（$p/3$ ずつ）と、格子手術の測定誤り・補助領域の誤り（$p_L$ × 距離 × 面積に比例）が $p_1,p_2$ に加わる。パッチは 1 cycle あたり $X$・$Z$ それぞれ $0.5\,p_L(d)$ の記憶誤り。5 量子ビットの密度行列を厳密に計算し（128 ビット演算で検証）、事後選択後の出力の不忠実度と成功確率を得る。量子ビット数と cycle 数は [Lit19] の費用式。公開ノートの 8 件を再現（N6）。

### 5.2 GoSC の配置への当てはめ（**本研究の当てはめ。仮定を含む**）
* **GoSC 15-to-1**（Fig. 17c：11 tiles × 11τ、1τ = $d$ cycles）：単一の距離 $d$。11 回転（Fig. 15、M1 で照合済み）それぞれに、時間方向の測定誤り $0.5\,p_L d$ と、2 tile の補助領域の空間方向の誤り $0.5\cdot2\,p_Ld$ を加え、各 tile に $0.5\,p_Ld$ の記憶誤り。量子ビット $11\times2d^2$、時間 $11d$ cycles / 成功確率。
* **GoSC 225-to-1**（Fig. 19：176 tiles × 15τ）：1 段目の 11 個の 15-to-1（距離 $d_1$）の出力（誤り $\varepsilon_1$、$P_{\pi/2}$ 型）を 2 段目（距離 $d_2$）の 15 回転に使う。1 段目の出力を補助領域で運ぶ誤りを $0.5\cdot5\,p_L(d_2)d_2$ とした（tile 数 5 は**仮定**）。量子ビット $2(121d_1^2+55d_2^2)$。
* 入力の魔法状態は確率 $p$ の Pauli 誤りを持つ（[GoSC] Sec. 4 の仮定。状態注入の回路は数えない；注入の費用は [Lit19] も同様に扱う）。

### 5.3 パッチの論理誤り率 $p_L(d,p)$ の較正（両方式を同じ雑音で比べるため）
[GoSC] 式 (10) $p_L=0.1(100p)^{(d+1)/2}$ は別の雑音モデル由来なので、そのまま使うと比較の前提がずれる。ただし、同じ雑音パラメータを使っても比較は対称ではない：Kobayashi 側は回路全体のモンテカルロ、Litinski 側はメモリの論理誤り率を入れた解析的な誤り予算（格子手術や蒸留器全体は回路レベルでシミュレーションしていない）。stim の回転表面符号メモリ回路を §3.1 の雑音モデル・6 ステップ/ラウンドに置き換え（`noisy_surface_code`；雑音なしで決定的・回路距離 $d$・6 ステップを N7 で確認）、MWPM で 1 ラウンドあたりの論理誤り（$X$ と $Z$ の和）を $d=3..11$、$p=0.002..0.006$ で求め、$p_L=A(p/p_{\rm th})^{(d+1)/2}$ を $p\le0.004$ の点に当てはめた。$p\le10^{-3}$ への外挿は、同じ形を仮定する（GoSC と同じ扱い）。$p_{\rm th}$ は当てはめの係数で、有限サイズスケーリングで求めた閾値ではない。不確かさは失敗数の二項分布による再標本化で示す。`PLOG_SOURCE='gosc'` で式 (10) に切り替えられる。

* 本来のシミュレーションのモデル（`main`、窓の項を $d\ge7$ に当てはめ）：届くのは B・要求 $10^{-4}$・$p=10^{-4}$（$d=3$、**0.54 倍**）と $p=2\times10^{-4}$（$d=5$、1.6 倍）。A・$p=10^{-4}$・要求 $10^{-4}$ は未確定（$d=7$、4.2 倍）。他は届かない。感度：`W5`（窓の項を $d\ge5$ に当てはめ）も同じ結論、`altW`（$d$ 依存を許す）では B・要求 $10^{-6}$・$p\le3\times10^{-4}$ で届くが 180〜860 倍。
* 診断（窓の雑音なし）のモデル：要求 $10^{-6}$ 以下で B 1.8〜13 倍、A 2.7〜39 倍（$p\le5\times10^{-4}$；$p=10^{-3}$ の A は届かない）。FSC を 8 ステップで数えると B 1.5〜11 倍、A 2.3〜33 倍。要求 $10^{-4}$ では B 0.37〜9.6 倍（$p\le2\times10^{-4}$ で 1 未満）、A 1.6〜24 倍。選ばれた $d$ の多くは $d>9$ や低い $p$ への外挿。

**解釈**：(i) 単一故障の床は $U$ 直前の $Z$ ラウンドの数という回路の選択に大きく依存していた（第 4 回レビューで判明）。(ii) 現在の実装で Kobayashi 方式が有利になりうるのは、アイドル雑音が小さく、$p\lesssim2\times10^{-4}$ で、要求精度が緩い（$\sim10^{-4}$）領域。(iii) 実用的な要求精度（$10^{-6}$ 以下）では、切り替えの窓に残る 2 次の誤りと、D4 相のラウンドの長さ（雑音の位置の多さ、体積 $\approx632d^3$）のため、蒸留の方が体積が小さい。窓の雑音を除いた診断でもその傾向は残る。(iv) 診断は最適な復号器の性能の上界・下界ではなく、外挿に依存し、資源の計数にも過小評価（FSC→パッチ変換、$X$ 補正の理想化、Litinski 側の注入）と過大評価（未最適化のスケジュール）の要因が両方ある。したがって、この結果は「本研究の回路・復号器と仮定のもとでのベンチマーク」であり、最適化された D4 方式に対する一般的な優劣を示すものではない。
