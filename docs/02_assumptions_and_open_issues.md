## 4. 検証失敗

なし（全項目 PASS。件数は `results/validation_*.json` と README を参照）。
* Litinski の多パッチ測定の構成では、最初に試した「全検査を手で決める」規則が非可換・余分な論理の測定で検証に失敗した。これは採用せず、「新しく測る検査だけを決め、残る旧検査は $\mathbb F_2$ 計算で決める」定式化に改め、全 11 回転で検証に通る単一の規則を探索で得た（`docs/04_review_response.md`）。
開発中に一度 FAIL となった項目（[Lit] 式(4) と式(2) の行空間の一致）は、検査の前提（列順が同じ）が誤っていたことによるもので、上の「文献に関する観察」に記録し、検査を「行変形＋列置換での同値」に改めた。

## 5. 比較の限界（§3.3 の再掲）
* ノイズ0では両方式とも理想出力を与え、完全な入力魔法状態があれば蒸留自体が不要。本比較は「指定した 2 プロトコルの回路構造と資源」の比較であり、最適な $T$ ゲート実装法を決めるものではない。
* `FT_ref` のラウンド数は耐故障性のための慣習・仮定であり、ノイズ下の論理誤り率は評価していない。
* 数値は特定の仮定（$\kappa$、ゲート時間、未構成の変換）のもとでの**予備的評価**であり、損益分岐と感度（比較ノート §4, §4b）が主な結果である。
* Kobayashi 方式は物理 CCZ を $\Theta(d^3)$ 個（$\kappa_{in}=1$ で $6(d-1)^2 d$ 個）用いるのに対し、Litinski 方式の物理非 Clifford 資源は $T$ 15 個。ノイズ下ではこの差が重要になりうる。
